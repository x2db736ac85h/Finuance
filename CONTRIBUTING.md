# Contributing

Thank you for your interest in Finuance!

Finuance is built phase by phase from a written plan ([roadmap](docs/ROADMAP.md)), so **pull requests are not accepted yet**: please open an issue first, and we can see where the change fits. This will open up with 1.0.

What helps right now:

- **Issues** with bugs, ideas or questions are welcome.
- **Bank layouts:** if your bank's CSV export doesn't import well, open an issue describing its layout (encoding, delimiter, header names, date and amount format). Please **never attach a real export**. If you want to share a sample, make up the values or run it through the [anonymiser](backend/cmd/anonymize) first.
- **Security issues:** report them privately, as described in [SECURITY.md](SECURITY.md).

If you want to run the project or its tests locally, the [README](README.md#quick-start) has everything you need.
