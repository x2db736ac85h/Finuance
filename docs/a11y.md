# Accessibility

Finuance aims at WCAG 2.1 AA. `web/e2e/a11y.spec.ts` runs [axe](https://github.com/dequelabs/axe-core)
(`@axe-core/playwright`, rules `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`) on every main screen in
both themes, and fails on any serious or critical violation:

sign-in, sign-up, the empty start screen, the table with the charts pane, the import window, the
overview, the four settings pages and the assistant panel.

## Fixed in Phase 14

| Finding (axe rule) | Where | Fix |
|---|---|---|
| `color-contrast` | Muted text (captions, column types, hints, `kbd`), accent-coloured links and the selected settings page, the white label of primary buttons in the dark theme, green "ok" text in the light theme | Tokens raised to 4.5:1 on every surface they appear on: dark `--muted` #6e6e77 → #919198, `--accent` #8b7cf6 → #9789f7, new `--accent-solid` #6d5ce7 behind white button text; light `--muted` #8e8e97 → #68686e, `--accent` #6d5ce7 → #6354d2, `--pos` #1e8e3e → #1a7a35. The legacy palette is otherwise unchanged. |
| `scrollable-region-focusable` | Top payees and category bars, the yield-on-cost bars, recurring payments, largest expenses, the overview highlights | The scrolling element is focusable (`tabindex="0"`) and labelled, so it can be scrolled with the keyboard |

## Keyboard-only checklist

Checked by hand at the gate (✓ = also covered by an E2E test).

| Task | Keys | |
|---|---|---|
| Sign in, sign up, sign out | Tab, Enter | ✓ `shell.spec.ts` |
| Open files to import | ⌘/Ctrl O, then the system file dialog | ✓ `quality.spec.ts` |
| Work through the import window: header row, column meanings, account, commit | Tab, arrow keys in selects, Enter; Esc closes | |
| Search all columns | ⌘/Ctrl F or `/`; Esc clears | ✓ `quality.spec.ts`, `table.spec.ts` |
| Move through the rows, open the inspector | ↑/↓ or K/J, PgUp/PgDn | ✓ `table.spec.ts` |
| Filter a column, hide columns | Tab to the column header button, Enter opens its menu | |
| Change the period, open a chart larger, step through charts | Tab, Enter; ←/→ in the chart window; Esc closes | ✓ `insights.spec.ts` (window) |
| Scroll a long chart list (payees, categories, recurring payments) | Tab to the list, arrow keys | ✓ axe rule |
| Select several rows, then group, categorise or mark them | Shift+↑/↓ (or Shift+J/K) from the open row; Tab to the quick bar | ✓ `rules.test.tsx`, `keys.test.ts` |
| Overview: change month, edit a budget or an investment | Tab, Enter, type, Tab away saves | |
| Assistant: open, ask, stop, close | ⌘/Ctrl J, type, Enter; Tab to Stop; ⌘/Ctrl J | ✓ `quality.spec.ts`, `assistant.spec.ts` |
| See every shortcut | `?`; Esc closes | ✓ `shell.spec.ts`, `quality.spec.ts` |
| Settings: theme, size, profile, sessions, data, migration | Tab, Enter, Space | |

Selecting several rows works from the keyboard since Phase 15 (Shift+↑/↓); only toggling single rows
out of a range (⌘/Ctrl-click) still needs the mouse.
